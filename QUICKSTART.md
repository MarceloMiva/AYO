# AYO v2.1 Quick Start

22-module offensive security framework for authorized pentesting, CTFs, and security testing.

## Installation
cd ~/AYO && python ayo.py

## Modules
- [7-11] Recon & OSINT: Username lookup, email breach, subdomain enum, dir bruteforce, hash cracking
- [12-22] Web & Network Attacks: SQLi, XSS, Web vuln scanner, SSH brute, WiFi scanner, ARP spoof, packet sniffer, port knocker
- [1-6] Evasion: File encryption, metadata cleaner, payload encoder, phishing kit, steganography, social engineering

For authorized testing only.
